# Shane Holloman • CV

A single-page CV built with Mintlify. The homepage includes a profile, expertise,
work history, studies, and education.

## Content

Edit `index.mdx` for CV content, `style.css` for layout and typography, and
`docs.json` for site settings and contact navigation.

Typography uses Roboto at weight 200 for the name, 900 for other headings,
and 400 for body text.

`favicon.svg` is the shared source for the browser icon and navbar mark.
It contains Lucide's `FingerprintPattern`, imported and generated by
`scripts/generate-logo.mjs`, with a `currentColor` stroke and no fixed
color. The navbar uses a CSS mask to inherit the theme highlight color;
`theme-icons.js` applies that same computed highlight color to the browser tab
icon whenever the theme changes. Change the imported icon in `scripts/generate-logo.mjs`
and run `bun run build:icons` to update the shape everywhere. The header logo is
20px; other header icons are 16px.

The header section, profile, and contact links use `header-navigation.js`. Its source,
`scripts/header-navigation.mjs`, imports icons and the SVG renderer directly from
the current `lucide` package. GitHub uses `CodeXml`, LinkedIn uses
`ContactRound`, and contact uses `Mail`. Theme controls, mobile menu controls, and
link arrows also use Lucide. The icons render as inline SVGs, inheriting the active
theme color. Other header icons match the 16px text size, with 40px item heights
and 24px gaps.
The library license is included in `LICENSE.lucide`.

Body section headings use Lucide icons from `scripts/body-icons.mjs`: fingerprint
for Profile, layers for Expertise, briefcase for Experience, book for Studies,
history for Earlier & independent work, and graduation cap for Education. These
decorative icons are 16px and inherit the heading color.

The Lucide search control opens a local section search implemented in
`scripts/cv-search.mjs`. It indexes the rendered CV content, ranks role and company
matches ahead of body mentions, and links results to stable anchors in `index.mdx`.
Search results use Lucide's `ChevronRight`; Mintlify's built-in icon library is
also configured as Lucide in `docs.json`.
Selecting a result closes the dialog and scrolls to that entry below the header.
It supports keyboard navigation, Command/Ctrl+K, and works without a Mintlify login.
Run `bun test scripts/cv-search.test.mjs` to check search matching and ranking.

After changing the header script, rebuild the checked-in browser bundle:

```sh
bun install --frozen-lockfile
bun run build:icons
```

The build minifies whitespace and identifiers while preserving statement syntax,
so the generated bundle passes Oxlint's `no-unused-expressions` rule. Check the
source and generated JavaScript with `bun run lint`; warnings fail this check.

Content was adapted from
[`shaneholloman/cv` • `RESUME.md`](https://github.com/shaneholloman/cv/blob/fdb7da300ef429de7e236ba81e07b972ae213175/RESUME.md).
Education entries follow that source, without inferring degree
completion. Content updates are manual.

## Preview and validate

### Local Aria voice prototype

Run `bun run dev` to start the Mintlify preview at `http://localhost:3000` and
the local Aria service at `http://127.0.0.1:8791`. Click the Aria icon immediately
after search, then **Start conversation**. Cove is fixed as the default voice,
and the voice selector is temporarily hidden. The component appears on
localhost, the live Mintlify CV, and the NAS-hosted combined preview.
It uses the current theme, Roboto typography, and the supplied Aria mark in
`aria.svg`, with no background
or fixed stroke color. Controls use imported Lucide icons.

Aria uses your existing **ChatGPT subscription login**, read by the local service
from Codex's auth store. Sign in or refresh that login with `codex login`.
The prototype never uses an API key and never sends your OAuth credentials to
the browser. The subscription Live transport follows the established Aria
voice application's authentication and WebRTC call contract. The control
connection uses Aria's subscription Live caption and client delegation events.
Luna supplies grounded answers; OpenAI Live handles the spoken conversation.
Public visitor OAuth is a separate next step. The NAS service uses the owner's
dedicated subscription login, with two concurrent voice sessions, a five-minute
session limit, two concurrent text requests, and 40 requests per ten minutes
across the service.

The local server reads the full CV directly from `index.mdx` for each new
conversation. Additional approved `.md` and `.txt` files can live outside this
repository in `~/.local/share/shane-cv-aria/knowledge/`. Set
`ARIA_KNOWLEDGE_DIR` to use another directory. Files in this directory are
agent knowledge and are not included in the site bundle. Only add material
you want Aria to be able to disclose to visitors.

Microphone access begins only after starting a conversation. Mute disables
its audio track. Ending the conversation, closing the dialog, or leaving the
page releases microphone capture and playback. A conversation ends after five
minutes. Session context stays in memory; the service does not save transcripts.
It binds to loopback and accepts local Mintlify origins. The NAS runtime also
accepts the live CV and its configured HTTPS service origin through the gateway.

Use `bun run dev:aria` to run just the voice service, `bun run test` for local
knowledge, service, and search checks, and `bun run lint` for JavaScript checks.

### NAS Aria workflow

Build on the Mac for the Synology's Linux x86-64 architecture. Never build on
the NAS. The Compose project has no build directive and uses its own directory,
`/volume1/docker/shane-cv-aria`, separate from Lina and other services.
The runtime is Bun 1.4.3, pinned by image digest. Aria and its gateway run on Bun;
the bundled Codex CLI supplies the headless login flow. Run `bun run test`
to check the service, token renewal, SSE and WebSocket proxy on Bun.

```sh
bun install --frozen-lockfile
bun run build:aria-preview
docker buildx build --platform linux/amd64 -t shane-cv-aria:preview --load .
mkdir -p /Volumes/tank/build-artifacts/shane-cv-aria
docker image save --platform linux/amd64 -o /Volumes/tank/build-artifacts/shane-cv-aria/preview.tar shane-cv-aria:preview
```

Transfer the image archive and `compose.yaml` to the NAS project directory.
This follows Lina Muses' existing deployment pipeline: a ready image, a standard
Compose file, a private `.env`, and persistent `data/`. No Container Manager
project wizard or NAS image build is needed.

Create `data/auth` and `data/knowledge` there, owned by UID/GID 1000. Keep the
auth directory mode 700 and the project directory private. Create an empty
`.env` with mode 600; it is reserved for runtime overrides. The Compose file
already supplies the preview origin and other non-secret defaults.

Load the ready image and start only this project:

```sh
cd /volume1/docker/shane-cv-aria
sudo /usr/local/bin/docker image load -i preview.tar
sudo /usr/local/bin/docker compose up -d --no-build --no-deps site
sudo /usr/local/bin/docker compose ps
```

To sign in **on the NAS**, run:

```sh
sudo /usr/local/bin/docker compose exec site bun /usr/local/bin/codex -c 'cli_auth_credentials_store="file"' login --device-auth
```

Open the displayed OpenAI link in your browser and enter the one-time code.
Device code login may need enabling in ChatGPT's security settings. The login
command runs inside the existing container and writes credentials directly into
the NAS's `data/auth` directory.
It does not copy or mount the Mac's login. Aria renews this dedicated login
before token expiry and saves rotated tokens with mode 600. Repeat the login
command if access is revoked or OpenAI requires another sign-in. The image and
Git repository contain no subscription credentials.

The existing `yoyo` Cloudflare Tunnel routes `aria.shaneholloman.dev` to
`http://20.0.0.3:18082`, matching Lina Muses' public-domain deployment pattern.
Cloudflare provides public DNS and HTTPS. The CV stays on Mintlify at
`shaneholloman.dev`; only Aria's API runs on the NAS. No Cloudflare Access login
is needed for this public hostname. The existing `*.yoyo.io` Access policy is
unchanged.

The gateway accepts only its configured hostname, trusted LAN/container source
addresses, and browser requests from the CV or its own origin. It strips
cookies and authorization headers before forwarding to either upstream.

`aria.yoyo.io` belongs to an existing machine at `20.0.0.41`. Do not repoint it
at the CV service. If the temporary Mac resolver override from the earlier
preview was installed, restore normal machine-name resolution with:

```sh
sudo /bin/sh /Volumes/tank/git/sources/shaneholloman/docs/scripts/restore-aria-machine-dns-macos.sh
```

This removes only the exact `/etc/resolver/aria.yoyo.io` rule installed during
preview and flushes the Mac DNS cache. No Mac, iPhone or UniFi DNS customization
is needed for the public Aria service.

The NAS preview fetches the published CV from Mintlify and adds its own Aria
assets after Mintlify initializes its custom header, preserving React hydration.
Preview analytics and CSP reports are acknowledged locally rather than sent to
the live CV's analytics. `/aria-api/` routes to the NAS voice service over loopback. Mintlify
remains the CV host. The Mac and its development server are not part of this
runtime path. Open `https://shaneholloman.dev` or the combined preview at
`https://aria.shaneholloman.dev` on iPhone. Allow microphone access after tapping
**Start conversation**.

Additional approved knowledge belongs in NAS `data/knowledge/`. Both knowledge
and authentication survive container replacement. `restart: unless-stopped`
restarts Aria after a NAS reboot. To roll back this preview, stop only the
`shane-cv-aria` Compose project and remove its single tunnel/DNS route; leave
other projects and tunnel rules untouched.

Install the [Mintlify CLI](https://www.mintlify.com/docs/installation):

```sh
bun add --global mint
bun run dev
```

Check internal links:

```sh
bun run --bun mint broken-links
```

The homepage is `index.mdx`. The former `/introduction` URL redirects to `/`.
Demo pages, API examples, and starter artwork have been removed.
